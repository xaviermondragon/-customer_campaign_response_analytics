# PySpark Pipeline to ingest, clean and analyse campaign data

## Data source:
The data used is this project was taken from  [kaggle](https://www.kaggle.com/datasets/nimishsawant/bankfull).
The data is related with direct marketing campaigns of a Portuguese banking institution which runs marketing campaigns to promote term deposits. The classification goal is to predict if the client will subscribe a term deposit.

## Goals:
Extract insights about customer behaviour and prepare data for Machine Learning-based customer targeting strategies.
